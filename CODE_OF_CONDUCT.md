# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful and constructive, assume good faith, and keep discussion focused on the work. Harassment, personal attacks, and discriminatory language are not tolerated.

Instances of unacceptable behaviour can be reported privately to the maintainer through the contact details on the [maintainer's GitHub profile](https://github.com/khs28). All reports will be reviewed and handled confidentially.
